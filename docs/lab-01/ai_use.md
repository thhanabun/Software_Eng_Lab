## Reflection

Constraining each prompt to one Issue with its acceptance criteria produced clean, reviewable diffs in one shot, while open-ended prompts caused scope creep I had to correct. I also verified everything the agent produced by re-running seeds, exercising both endpoints, stopping the database to prove the error state, and comparing git trees — the agent assisted, but I reviewed and approved every command and file.
